## v0.4.0 → v0.4.1 新增修复

### T-22b 修复：Wiki-link 图片列检测

**问题：** v0.4.0 中 `_compute_col_widths()` 无法检测 wiki-link 格式的图片（`![[path]]`）。  
原因：流水线顺序 — `image_rewriter` 先于 `table_cleaner` 运行，把 HTML 表格内的 `<img src="...">` 转为 `![[wiki-link]]`。

**修复：**
```python
# 改前（v0.4.0）
if re.search(r"<img\b", cell.inner_html, re.IGNORECASE):
    col_has_img[j] = True

# 改后（v0.4.1）
if re.search(r"<img\b|!\[\[", cell.inner_html, re.IGNORECASE):
    col_has_img[j] = True
```

**验证（导购PRD 文档）：**
- 表格结构：3 列（模块 | 图示 | 详细）
- v0.4.0 输出：`10% | 45% | 45%` ❌（图片列误判为 wide）
- v0.4.1 输出：`10% | 25% | 65%` ✅（图片列正确分配）
